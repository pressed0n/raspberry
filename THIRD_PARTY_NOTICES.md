# Third-party dependencies

Raspberry currently consumes published packages without editing their source. Keep their license/copyright files in distributions. This direct-dependency summary is not a replacement for a full transitive distribution audit.

| Package | Installed license metadata |
| --- | --- |
| Next.js, React, React DOM | MIT |
| BlockNote core, React integration, Mantine integration | MPL-2.0 |
| Mantine core/hooks | MIT |
| Model Context Protocol TypeScript SDK | MIT |
| Lucide React | ISC |
| node-postgres (`pg`) | MIT |
| Zod | MIT |

BlockNote's bundled font files and transitive dependencies retain their accompanying licenses. No BlockNote XL or Tiptap paid extensions are intentionally included. Verify the exact lockfile and dependency notices again before publication.

The Raspberry berry mark is an original SVG asset in this project. Raspberry's own distribution license remains an explicit publication decision.
